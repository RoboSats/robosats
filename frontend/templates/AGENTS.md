# /frontend/templates — HtmlWebpackPlugin Templates

## Purpose

Contains the HtmlWebpackPlugin EJS source template (`index.ejs`) and gitignored build
outputs (`basic.html`, `pro.html`). The outputs are generated by `npm run build` and
injected by CI — **never hand-edit them and never commit them**.

## Files

| File                  | Status                                    | Role                                                       |
| --------------------- | ----------------------------------------- | ---------------------------------------------------------- |
| `frontend/index.ejs`  | Source — edit this                        | HtmlWebpackPlugin template; produces all HTML entry points |
| `frontend/basic.html` | **Gitignored build output — CI-injected** | Django template for web-basic + selfhosted-basic           |
| `frontend/pro.html`   | **Gitignored build output — CI-injected** | Django template for web-pro + selfhosted-pro               |

`desktopApp/index.html` and `android/.../assets/index.html` are also generated from
`index.ejs` — they live outside this directory and are also gitignored.

## `index.ejs` — Key Injections

HtmlWebpackPlugin renders `index.ejs` with `templateParameters` injected at build time:

| Parameter          | Source                                              | Effect                                                                       |
| ------------------ | --------------------------------------------------- | ---------------------------------------------------------------------------- |
| `robosatsSettings` | webpack HtmlWebpackPlugin options                   | `window.RobosatsSettings = '<%= robosatsSettings %>'` (set inside WASM gate) |
| `basePath`         | per-target config (`/` or `file:///android_asset/`) | Prefix for all asset `<link>`/`<script>` `href`/`src`                        |
| `pro`              | `true` for pro targets, `false` otherwise           | Loads `css_pro/` stylesheets + sets title "RoboSats PRO"                     |
| `mobile`           | `true` for Android target only                      | Omits `<link rel="icon">` favicons (inlined in APK)                          |

### Asset Loading

All targets: `css/loader.css`, `css/index.css`, `css/leaflet.css`.
Pro-only (`<% if (pro) { %>`): `css_pro/fonts.css`, `css_pro/react-grid-layout.css`, `css_pro/react-resizable.css`.
Non-mobile only (`<% if (!mobile) { %>`): favicon `<link>` tags.

### WebAssembly Gate

`window.RobosatsSettings` is assigned **inside** the `if (window.WebAssembly)` branch:

```javascript
if (window.WebAssembly) {
  window.RobosatsSettings = '<%= robosatsSettings %>';
  document.querySelector('.js-enabled-content').style.display = 'block';
} else {
  document.querySelector('.noscript-error').style.display = 'block';
}
```

Without WASM: `window.RobosatsSettings` is **never set** and the app silently shows `.noscript-error` instead of loading.

### Loader Quotes

5 rotating quote slides are rendered inside the loader element — shown while the React bundle is parsed/executing.

### Django Template Placeholder

```html
<meta http-equiv="onion-location" content="{{ ONION_LOCATION }}" />
```

Django's `views.py` substitutes it when serving `basic.html`/`pro.html` directly (coordinator deployment). In nodeapp/desktop/Android context the placeholder is left literal — it's inert but visually confusing in the raw HTML.

## Django Integration

`frontend/views.py` renders `frontend/basic.html` or `frontend/pro.html` passing `ONION_LOCATION` from python-decouple config. The templates are registered as Django templates (app `frontend` in `INSTALLED_APPS`), not static files.

## Traps

- `basic.html` and `pro.html` are **gitignored generated outputs** — they are never tracked
  in git. Running `npm run build` overwrites any local copy. CI injects the correct build
  artifact at release time. Never hand-edit them; change `index.ejs` instead.
- Without WASM, `window.RobosatsSettings` is never set — the app shows `.noscript-error` silently with no JS error thrown.
- The `{{ ONION_LOCATION }}` Django variable appears literally in `desktopApp/index.html` and Android assets — never rendered there, inert but present.
- `basePath` values per target: `file:///android_asset/` for Android; `/` for web, nodeapp,
  and desktop. Only `publicPath` is relative (`./static/frontend/`) for desktop and Android
  — `basePath` is always absolute `/` for those targets too. Mixing them breaks asset loading.

## Constraints

- Never hand-edit `basic.html` or `pro.html` — they are webpack outputs.
- Never commit `basic.html` or `pro.html` — they are gitignored; CI injects them.
- Edit `index.ejs` for any change to the HTML shell, `<head>` tags, or `window.RobosatsSettings` injection.
- After editing `index.ejs`, run `npm run build` to verify the regenerated output locally.
